# Translate Health — Sitemap & Content Outline

## Site Architecture

### 1. Homepage (`/`)
**Goal:** Convert visitors to waitlist signups or demo requests

**Sections:**
1. **Hero** — Tagline + subhead + primary CTA + product screenshot/mockup
2. **The Problem** — 3 pain points with micro-copy (memory, communication, coordination)
3. **How It Works** — 4-step visual flow: Talk → Translate → Analyze → Share
4. **The Agent Team** — Brief intro to the 7 agents (expandable/cards)
5. **For Patients** — Benefits + testimonial placeholders
6. **For Providers** — B2B wedge + report preview
7. **Trust & Privacy** — HIPAA-aligned, encryption, data ownership
8. **Final CTA** — Waitlist signup or "See how it works" demo CTA
9. **Footer** — Links, social, legal

### 2. How It Works (`/how-it-works`)
**Goal:** Deep dive into the product experience

**Sections:**
1. **The Conversation** — Show actual text exchanges (anonymized/recreated)
2. **The Agents** — Detailed breakdown of each agent with visuals
3. **The Reports** — Provider report preview (mock PDF screenshot)
4. **The Dashboard** — Dashboard mockup with sparklines and trends
5. **Security & Privacy** — Technical details on encryption, BAAs, data handling

### 3. For Providers (`/for-providers`)
**Goal:** B2B conversion — get providers interested

**Sections:**
1. **The Problem** — "Your patients can't remember their symptoms. You get 5 minutes."
2. **The Solution** — Structured reports, better appointments, patient engagement
3. **Report Preview** — Actual mock report layout
4. **Practice Integration** — How it works at scale
5. **Pricing** — Practice tier ($99/mo) + Health System (custom)
6. **Contact/Request Demo** — Form

### 4. Features (`/features`)
**Goal:** Comprehensive feature listing for comparison shoppers

**Sections:**
1. **Natural Language Check-ins** — SMS, WhatsApp, web
2. **Pattern Detection** — Correlations, trends, anomalies
3. **Provider Reports** — Specialty-tailored, shareable
4. **Data Integration** — Epic, wearables, manual entry
5. **Privacy & Security** — HIPAA, encryption, data ownership
6. **Coming Soon** — Voice input, mobile app, provider portal

### 5. About (`/about`)
**Goal:** Humanize the company, tell the origin story

**Sections:**
1. **Origin Story** — Dylan's personal health journey (CIDP, ADHD, motorcycle crash)
2. **Built by Patients, for Patients** — Why this exists
3. **Team** — Dylan + contributors (can be minimal for now)
4. **Mission** — Better chronic care through better data

## Content Requirements

### Visual Assets Needed
1. **Hero illustration** — Abstract representation of translation/communication (not literal translation, more like "chaos → clarity")
2. **Agent icons** — 7 simple, consistent icons for the agent team
3. **Product screenshots** — SMS conversation, dashboard, provider report
4. **Report mockup** — Clean, clinical but readable PDF preview
5. **Dashboard mockup** — Sparklines, trend cards, correlation visualizations

### Copy Requirements
- All copy should be concise, warm, and specific
- Avoid generic health app language ("empowering your wellness journey")
- Use real examples from Dylan's actual health tracking
- Include specific stats where possible ("2.3x higher pain after poor sleep")
